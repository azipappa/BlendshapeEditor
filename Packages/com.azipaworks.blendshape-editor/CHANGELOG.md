# Changelog

このプロジェクトの主な変更内容を記録します。

## [1.0.0]

初回リリース。

### Added

#### シェイプの作成
- 既存のシェイプキーを組み合わせて新しいシェイプキーを作る機能を追加
- 元にするシェイプごとに、新シェイプ 100 のときの値を指定する機能を追加（頂点・法線・接線を合成、中間フレームに対応）
- 「限界突破」オプションを追加（±100 を超える値を設定可能。上限は既定 ±300、100〜1000 で変更可）
- 対象メッシュで値が入っているシェイプだけから選ぶ絞り込みと、今の値を打ち消す値を入れる「打消」を追加
- 既存シェイプを編集する機能を追加（選んだシェイプと同じ名前で出力し、元にするシェイプにそのシェイプを設定）
- 左右分割（左側のみ / 右側のみ / `_L` と `_R` の両方）を追加
- 一覧を見やすく区切るための「UI用シェイプ」（顔を変形しない空のシェイプ）の作成を追加
- 新しいシェイプを入れる位置（先頭 / 「〇〇 の下」 / 既定の位置）を選ぶ機能を追加
- シーン上でのリアルタイムプレビューと、プレビュー状態の表示（ウィンドウとシーンビューの帯・枠）を追加

#### 保存と元に戻す
- 元の FBX を変更せず、シェイプを追加したメッシュを `.asset` として保存する機能を追加
- 作る前の顔のデータと全シェイプの設定を保存ファイルに同梱し、保存のたびに作る前の顔から作り直す仕組みを追加
- 既存の名前で作ったとき、元のシェイプを接尾辞（既定 `_orig`）付きの名前で退避用の見出し（既定 `--- Blendshape Editor ---`）の下に残す機能を追加
- 作成したシェイプの一覧（編集・削除）を追加
- アバターの FBX を更新したときに最新の顔に合わせて作り直す機能を追加
- 不要になった保存ファイルを削除する機能を追加（使用中のファイルは削除不可、参照しているシーン・プレハブを警告）

#### 並び順
- 既存のシェイプを含む全シェイプキーの並び替え（ドラッグ＆ドロップ、複数選択、検索、保存ボタンで反映）を追加
- 並び替えの Undo / Redo（Ctrl+Z / Ctrl+Y）を追加
- 変更前と変更後を左右に並べて比較する表示を追加（移動したシェイプと移動量を表示）

#### アバター管理
- シーンの全アバターを一覧にし、今の保存ファイルを反映する / 反映前に戻す機能を追加
- 反映前の状態（使っていたファイル・各シェイプの値・瞬き/視線の設定）の記録と、記録どおりに戻す機能を追加
- 反映の履歴と、その回の反映だけを取り消す機能を追加
- Avatar Descriptor の瞬き・視線（番号で参照）のずれの検出と、名前での付け直しを追加
- 同じアバター用に作った保存ファイルがある場合に、作り直さずに使えるよう案内する機能を追加

#### ライセンス
- 購入したコンピュータでのみ利用できるライセンス確認を追加（未購入時はウィンドウ全体を使えない）
- Booth 購入者向けのライセンスインストーラー（`BlendshapeEditor_License.unitypackage`）を追加（インポートするだけでインストール）
- ライセンス削除メニュー `Tools > Azipa Tools > ライセンス管理 > Blendshape Editor ライセンス削除` を追加

#### その他
- Unity Editor のメニュー `Tools > Azipa Tools > Blendshape Editor` にウィンドウを追加
- シーン保存・再生・アップロード前にプレビューを自動で解除する安全制御を追加
- VRChat SDK が無い環境でも動作する構成を追加（瞬き・視線の機能は VRChat SDK - Avatars がある場合のみ有効）
- VPM パッケージ `com.azipaworks.blendshape-editor` として配布できる構成を追加
